## ‘답·추천·질문’에 대한 판단

리뷰는 각 불일치를 ‘답’(근거로 정답이 정해진 것), ‘추천’(권고), ‘질문’(owner 결정이 필요한 것)으로 나눴다.

### 답 21건

- 원본·가이드·owner 결정으로 확인해 반영했다.
- MM-19 답의 내보내기 보안/epoch/실제 정리는 채택했다.
- 하지만 **부가 추천인 JSON+Evidence zip 형식은 확정하지 않았다**.
  - 왜: plan contracts §2.2는 `/export` 다운로드와 비밀값·수신자 제외만 정한다. 그래서 특정 zip 구성을 새 필수기능으로 늘리지 않는다.
- 기존 원본 JSON과 실제 제품 결과 형식은 구분해 테스트한다.
