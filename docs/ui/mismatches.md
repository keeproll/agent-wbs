# 불일치·죽은 동작·미결 사항

판정 우선순위는 **owner 결정 → 계획 기준선 b258334 → 가이드 → 원본**이다. 아래 `원본`은 Main.dc.html, `가이드`는 Agent-WBS-설계의도-및-구현가이드.md 줄 번호다. 제품 코드를 수정한 보고서가 아니다. 단순 Mock 교체 작업과 실제 모순을 구분했다. 저자의 최초 브라우저 재현은 환경 제한으로 못했으나 독립 리뷰가 브라우저로 확인한 증거를 추가했다(screenshots.md). `VM 확인` 표시는 [probe.mjs](probe.mjs)에서 원본 로직을 실행해 확인한 결과다.
