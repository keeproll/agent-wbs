### Q-09 GitHub
- 출처: G L219(private·main), L468·L1039(int 필수·보호 규칙 이중 방어 **확정**), L235·L242·L257(최초 커밋·입력 push·되돌림 push). 필수 검사와 이 push들을 함께 쓰려면 우회 범위가 필요하고 요금제에 따라 규칙 지원이 다를 수 있다(확인 필요).
- 선택지(보호): (A) 보호 규칙을 쓸 수 있는 저장소/요금제 + 지정 계정만 우회, 우회 커밋은 owner 입력 push·최초 생성·초기화 되돌림만. 일반 병합은 int 통과한 병합본만 / (B) 입력·초기화도 포함해 전부 PR. 보호 규칙 없이 Runner 검사만 하는 것은 **G 충족이 아니며** owner의 명시적 범위 변경 승인이 필요해 선택지에서 제외
- 선택지(인증): (가) `gh` 로그인 / (나) 저장소 한정 fine-grained 토큰
- **추천: A + (나).** 필요한 입력: 시험 저장소 주소, 요금제, 인증, git-lfs 필요 여부. 이 PC에는 `gh`·`git-lfs`가 없다.
